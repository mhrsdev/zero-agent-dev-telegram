## 3. Bugs found during THIS round → fixed → pinned

1. **GAP H — compaction summarizer ignored `routing.primary_model`.** The planner,
   chat bridge, and scheduler tick were aligned in earlier rounds, but the
   compaction LLM summarizer still resolved its model from
   `settings.openai_model` (the gpt-4o-mini default). On the operator's gateway
   every summarizer call failed → compaction silently degraded to the
   deterministic template → **LLM-gated memory deltas (GAP 9) could never be
   extracted in real deployments**. Fix: `CompactionService.summarizer_routing`
   override set by config sync (same routing truth as everything else); the
   summarizer honors it with a registered-adapter fallback. Hermes reference:
   its auxiliary compression uses the configured primary model, not a hardcoded
   default. Pinned: 4 tests in `tests/test_hermes_parity_round9_compaction.py`.

2. **GAP I — `GET /projects/{pid}/rag` returned 500.** The route called
   `list_rag_documents()` without the now-required keyword-only `actor_id` →
   TypeError on EVERY call. Never exercised live before round 9. Fixed (pass the
   authorized actor). Found via a full router scan for the same defect class.

3. **GAP J — `GET /projects/{pid}/agent-types/{tid}/knowledge` returned a
   misleading 404** for the same reason (missing `actor_id` kwarg). The live run
   surfaced it as `count=1` (the 404 detail dict). Fixed; scan confirms no other
   call site remains. Pinned: `tests/test_hermes_parity_round9_routes.py`.

4. **GAP K — duplicate RAG ingest returned 500.** Re-ingesting the same
   (source_type, source_id) escaped as a raw IntegrityError. The typed
   `RagDocumentAlreadyExistsError` now maps to an honest **409 Conflict**.
   Pinned: duplicate-ingest test (409 + detail).

5. **GAP L — delegation left NO durable audit trail.** The `delegate` tool is
   runtime-owned and bypasses the static tool registry, so it also bypassed the
   `tool.invoke` audit every registry tool writes. Spawning sub-agents (with
   real provider calls) was invisible in audit_events. Fix: AgentRuntime now
   takes an `audit_repo` and writes `tool.invoke`/`target_id='delegate'` audit
   rows on every delegation exit path (success and error), with redacted,
   bounded summaries. Wired in composition; `getattr`-guarded so `__new__`-
   built test runtimes are unaffected. Pinned: 2 tests in
   `tests/test_hermes_parity_round9_delegation.py` + live proof (D3: audit
   rows=1 on the real engine).
